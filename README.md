# Employee Engagement Dashboard 2026

Dashboard สำหรับวิเคราะห์ข้อมูล Employee Engagement Survey สำหรับผู้บริหารและผู้จัดการ

## ฟีเจอร์

- **KPI Cards**: คะแนนรวม, จำนวนผู้ตอบ, มิติดีสุด/ต้องปรับปรุง
- **ภาพรวม 7 มิติ**: 
  - องค์กร (Organizational Engagement)
  - ผู้นำ (Leadership)
  - งาน (Job)
  - พัฒนา (Development)
  - สื่อสาร (Communication)
  - สภาพแวดล้อม (Work Environment)
  - ผลตอบแทน (Compensation)
- **Charts**: Radar, Bar Chart, Heatmap
- **Top 5**: จุดแข็งและข้อที่ต้องปรับปรุง
- **Insights**: ข้อเสนอแนะอัตโนมัติ

## วิธีใช้

1. เปิด `dashboard.html` ในเบราว์เซอร์
2. คลิก "เลือกไฟล์ Excel"
3. เลือกไฟล์ Employee Engagement Survey 2026 (Responses).xlsx
4. Dashboard จะแสดงข้อมูลอัตโนมัติ

## เทคโนโลยี

- HTML5, CSS3, JavaScript
- Chart.js (Charts)
- SheetJS (XLSX parsing)
- Google Fonts (Prompt)
